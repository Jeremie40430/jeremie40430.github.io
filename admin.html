Modifier le site

Remplis les champs, clique sur Générer, puis colle le résultat dans GitHub. Tu n'as aucune syntaxe à respecter : les guillemets et les virgules sont écrits pour toi. Les champs laissés vides gardent le texte par défaut du site.

Infos pratiques
Il reste trois clics.
  1. Ouvre le fichier infos.js sur GitHub.
  2. Sélectionne tout le contenu existant et colle ce qui a été copié à la place.
  3. Clique sur le bouton vert Commit changes. Le site est à jour une minute plus tard.
